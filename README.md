# چراغ‌ها را بگیر — مسابقهٔ غرفهٔ زانیس

بازی سرعت برای غرفهٔ «صنایع روشنایی زانیس». صفحه‌ای از محصولات زانیس نشان داده می‌شود و هر بار چند محصول روشن می‌شوند:

- **زرد روشن شد؟ بزن!** امتیاز می‌گیری.
- **قرمز با ضربدر؟ دست نزن!** زدنش امتیاز کم می‌کند.

هر دور ۳۰ ثانیه است. بازی با «حالت عادی» شروع می‌شود و دقیقاً در ثانیه‌ای که در داشبورد تعیین شده (پیش‌فرض ۱۵) یک بار و بدون هیچ پیامی به «حالت سخت» می‌رود: تندتر، با چند چراغ زرد و چند چراغ قرمز هم‌زمان. تا آخر دور هم سخت می‌ماند. همهٔ این عددها از داشبورد وب عوض می‌شوند.

| بخش | کار | کجا |
|-----|-----|-----|
| اپ اندروید (APK) | **فقط تمرین**: بدون ثبت‌نام، هر چند بار که بخواهی؛ امتیازی ثبت نمی‌شود | `android/` |
| بازی ویندوز (exe) | **مسابقهٔ اصلی**: نام و موبایل، یک دور، ثبت امتیاز روی سرور؛ نوار رد‌شوندهٔ برترین‌ها و آخرین امتیازها پایین صفحه | `desktop/` |
| سرور و داشبورد | تنظیمات بازی، همهٔ امتیازها، کلید رایانه‌های غرفه | `server/` — https://zgp.game.aliizz.ir |

هر سه از یک وب‌اپ مشترک در `web/` ساخته می‌شوند.

## دانلود

- **APK و exe:** آخرین نسخه در [Releases](../../releases/latest). همین دو فایل روی FileBox (mainfile.emanstore.ir) هم گذاشته می‌شوند.
- **از داشبورد:** بخش «دانلود و QR» دکمهٔ دانلود هر دو فایل و QR کد قابل چاپ هرکدام را دارد. سرور هر ۱۰ دقیقه آخرین Release را از گیت‌هاب برمی‌دارد و خودش نگه می‌دارد. لینک‌های `https://zgp.game.aliizz.ir/download/android` و `/download/windows` عمومی‌اند تا بازدیدکننده با اسکن QR بدون ورود دانلود کند.
- **exe ویندوز:** قابل‌حمل است و نصب نمی‌خواهد (ویندوز ۱۰ و ۱۱، ۶۴ بیتی). تمام‌صفحه باز می‌شود؛ F11 یا Esc از تمام‌صفحه خارج می‌کند و Alt+F4 می‌بندد.
- **تمرین در مرورگر:** https://zgp.game.aliizz.ir/play/

## راه‌اندازی غرفه (یک بار)

1. در داشبورد وارد شوید. بخش «دستگاه‌ها» را باز کنید و برای هر رایانهٔ غرفه یک کلید بسازید. کلید فقط همان یک بار نشان داده می‌شود.
2. بازی ویندوز را باز کنید و لوگوی زانیس را حدود دو ثانیه نگه دارید. رمز پیش‌فرض پنل `1405` است؛ همان روز اول عوضش کنید.
3. در پنل مسئول، کلید را در «کلید این دستگاه» بگذارید و «ذخیره و آزمایش اتصال» را بزنید. باید پیام «وصل شد» بیاید.

## کار با سرور

- **تنظیمات:** اپ‌ها تنظیمات را از سرور می‌گیرند. بازی ویندوز هر ۳۰ ثانیه آن‌ها را تازه می‌کند و اپ اندروید هر بار که به صفحهٔ شروع برمی‌گردد.
- **بی‌اینترنت:** آخرین تنظیمات روی دستگاه می‌ماند. امتیازهای بازی ویندوز صف می‌شوند و با برگشتن اتصال خودشان ارسال می‌شوند. وضعیت صف در پنل مسئول دیده می‌شود.
- **نوار امتیاز:** فقط نام کوچک و حرف اول نام خانوادگی را نشان می‌دهد (مثلاً «علی ر.»)، نه شماره را.
- **دفعات بازی:** محدودیت هر شماره (برای جلوگیری از تکرار بازی) در داشبورد تنظیم می‌شود. صفر یعنی نامحدود.
- **فهرست کامل:** نام، موبایل و همهٔ امتیازها فقط در داشبورد است: بخش «خلاصه و برترین‌ها» برای اعلام برنده‌ها، و «همهٔ امتیازها» با خروجی CSV.

## تنظیمات بازی (داشبورد)

| تنظیم | پیش‌فرض |
|-------|---------|
| زمان هر دور | ۳۰ ثانیه |
| ثانیهٔ سخت شدن (فقط یک بار) | ۱۵ |
| حالت عادی | هر موج ۱٫۲ ثانیه روشن · یک زرد · تا یک قرمز (۳۰٪) |
| حالت سخت | هر موج ۰٫۷ ثانیه روشن · دو زرد · تا دو قرمز (۵۰٪) |
| مکث بین موج‌ها | ۰٫۱۵ ثانیه |
| جدول محصولات (چند در چند) | ویندوز ۵×۵ · اندروید ۳×۴ |
| امتیازها | زرد +۲ · قرمز −۳ · خانهٔ خاموش −۱ · زرد جامانده ۰ |
| نوار امتیاز | ۱۰ برترین امروز + ۱۵ بازی آخر |

محدودهٔ مجاز هر عدد هم در `server/src/Zanis.Games.Api/Game/GameSettings.cs` تعریف شده و هم در `web/js/game/settings.js`. این دو را همیشه با هم تغییر دهید.

## ساختار

```
web/              بازی (HTML/CSS/JS خالص، بدون مرحلهٔ بیلد)
  js/game/        قواعد بازی (engine، settings) و صفحهٔ یک دور (lights)
  js/core/        ذخیره روی دستگاه، ارتباط با سرور (sync)، نوار امتیاز، صدا
  js/app.js       حالت تمرین (اندروید/مرورگر) و حالت مسابقه (ویندوز یا ‎?mode=kiosk)
android/          پوستهٔ اندروید: WebView تمام‌صفحه
desktop/          پوستهٔ ویندوز: Electron؛ preload حالت مسابقه را روشن می‌کند
server/           سرور ‎.NET 10 (Minimal API + SQLite) و داشبورد (wwwroot)
  deploy/         docker compose، سایت nginx و deploy.sh
test/             تست‌های بازی (node --test)
videos/           ویدئوهای شبیه‌سازی نسخهٔ قبلی (جدا از بازی)
```

## توسعه

```bash
# بازی در مرورگر (حالت مسابقه: http://localhost:8123/?mode=kiosk)
python -m http.server 8123 --directory web

# تست‌های بازی
node --test test/*.mjs

# تست‌های سرور
dotnet test server/Zanis.Games.slnx
```

APK و exe فقط در GitHub Actions ساخته می‌شوند (`.github/workflows/build.yml`). هر push روی `main` که `web/`، `android/` یا `desktop/` را عوض کند، یک Release تازه با APK امضاشده و exe می‌سازد. کلید امضا در GitHub Secrets است و در ریپو نیست. تست‌های سرور در `server.yml` اجرا می‌شوند.

## استقرار سرور

سرور روی `5.202.255.203` اجرا می‌شود و به هیچ سرویس دیگری وابسته نیست:

- کلون ریپو در `/opt/zanis-games/repo`.
- حساب داشبورد در `/opt/zanis-games/.env` با دسترسی 600.
- داده (فایل SQLite و کلیدهای کوکی) در volume داکر `zanis-games-data`.
- nginx میزبان، TLS این نام را با گواهی جداگانهٔ Let's Encrypt (acme.sh) باز می‌کند و درخواست را به `127.0.0.1:18300` می‌دهد.

```bash
/opt/zanis-games/repo/server/deploy/deploy.sh        # آخرین main: بیلد (همراه تست)، اجرا، بررسی سلامت
/opt/zanis-games/repo/server/deploy/deploy.sh cert   # گرفتن گواهی و نصب سایت nginx (یک بار؛ تمدید خودکار است)
```

## حریم خصوصی

- نام و موبایل بازیکن‌های ویندوز روی سرور ذخیره می‌شود. فقط داشبورد که رمز دارد آن‌ها را نشان می‌دهد.
- API عمومی فقط تنظیمات و نام کوتاه‌شده با امتیاز را برمی‌گرداند.
- ثبت امتیاز بدون کلید رایانهٔ غرفه ممکن نیست. اپ اندروید هیچ دادهٔ شخصی‌ای نمی‌گیرد.
