# بازی‌های نمایشگاهی زانیس

اپ اندروید بازی‌های غرفه برای «صنایع روشنایی زانیس»: یک اپ با منوی ۱۰ بازی، ثبت نام و شمارهٔ بازدیدکننده، جدول برترین‌ها و پنل مسئول غرفه. اپ کاملاً آفلاین است و همهٔ داده‌ها روی همان دستگاه می‌ماند.

## دانلود

- **APK:** آخرین نسخه در [Releases](../../releases/latest) (اندروید ۸ به بالا).
- **ویدئوهای شبیه‌سازی:** در [Release «videos»](../../releases/tag/videos).

## راهنمای مسئول غرفه

- **پنل مسئول:** لوگوی زانیس را در صفحهٔ اصلی حدود دو ثانیه نگه دارید. رمز پیش‌فرض `1405` است؛ همان روز اول عوضش کنید.
- **در پنل:** فهرست بازدیدکننده‌ها (خروجی CSV برای ارسال)، موجودی و شانس هر جایزه، تعداد دفعات مجاز بازی شانسی برای هر نفر، کدهای ایستگاه‌های پاسپورت، خاموش و روشن کردن صدا، و پاک کردن داده‌ها.
- **جایزه‌ها:** وقتی موجودی یک جایزه صفر شود دیگر در بازی‌های شانسی درنمی‌آید.
- **نفر بعدی:** دکمهٔ «نفر بعدی» بازدیدکنندهٔ فعلی را خارج می‌کند؛ امتیازها و جایزه‌هایش با شماره‌اش می‌ماند.
- **پاسپورت:** کد چهاررقمی هر ایستگاه را چاپ کنید و کنار همان بخش غرفه بگذارید.
- **دکمهٔ برگشت اندروید** اپ را نمی‌بندد و به منوی بازی‌ها برمی‌گردد. برای حالت کیوسک کامل، «سنجاق کردن برنامه» (Screen pinning) اندروید را روشن کنید.

## شخصی‌سازی

| چه چیزی | کجا |
|---------|-----|
| جایزه‌ها، موجودی اولیه، ایستگاه‌های پاسپورت | `web/js/data/config.js` |
| محصولات (نام، خانواده، عکس) | `web/js/data/products.js` و `web/img/products/` |
| سؤال‌های مسابقه | `web/js/data/quiz.js` |
| رنگ‌ها و ظاهر | `web/css/app.css` (متغیرهای `:root`) |

> محصولات، عکس‌ها و سؤال‌های کاتالوگ از سایت [zaniselec.com](https://zaniselec.com) برداشته شده‌اند (۲۴ محصول از همهٔ خانواده‌ها). تعداد موجودی جایزه‌ها در `config.js` فرضی است و باید پیش از نمایشگاه تنظیم شود. با هر تغییر جایزه یا ایستگاه، `CONFIG_VERSION` را یکی زیاد کنید.

## ساختار

```
web/            اپ بازی‌ها (HTML/CSS/JS خالص، بدون مرحلهٔ بیلد)
  js/core/      ذخیره‌سازی روی دستگاه، صدا، ابزارها
  js/data/      تنظیمات غرفه، محصولات، سؤال‌ها
  js/games/     هر بازی یک ماژول با رابط یکسان { id, title, kind, mount(stage, api) }
  js/app.js     مسیریابی، ثبت‌نام، منو، میزبان بازی، برترین‌ها، پنل مسئول
android/        پوستهٔ اندروید: یک WebView تمام‌صفحه که web/ را از assets اجرا می‌کند
videos/         صحنه‌های انیمیشنی (scenes.js) و رندرکنندهٔ MP4 (render.mjs)
test/           تست‌های واحد (node --test)
```

## توسعه

```bash
# اجرای اپ در مرورگر
python -m http.server 8123 --directory web

# تست‌ها
node --test test/*.mjs

# پیش‌نمایش یک صحنهٔ ویدئو
python -m http.server 8124    # سپس http://localhost:8124/videos/scenes.html?scene=buzz-wire
```

ساخت APK و ویدئوها در GitHub Actions انجام می‌شود (`.github/workflows/build.yml` و `videos.yml`). هر push روی `main` که `web/` یا `android/` را عوض کند یک APK امضاشده می‌سازد و به‌صورت Release منتشر می‌کند. کلید امضا در GitHub Secrets است و در ریپو نیست.

## حریم خصوصی

نام و شمارهٔ موبایل بازدیدکننده‌ها فقط روی همان دستگاه ذخیره می‌شود، در پشتیبان‌گیری ابری اندروید قرار نمی‌گیرد و فقط با خروجی CSV پنل مسئول از دستگاه بیرون می‌رود.
